## 图标
- 风格：Fluent 线性图标，24×24 视窗，1.5px 描边，圆头圆角连接，随文字着色
- 所需图标：Mic / Gear / Lock / ChevronDown / ChevronRight / Send / Spinner / X / Minus / Square（+书签 Bookmark 备用）
- 实现方式：epaint 手绘矢量（与设计源码同几何），不用位图

## 交互态与动画
- 行 hover: rgba(128,128,128,0.14) · 关闭钮 hover: 底 #E5484D、图标白
- spinner: 0.9s 线性无限旋转 · VAD 概率条演示: 2.4s ease-in-out 循环
- PTT 按下: 胶囊底变 #0078D4、文字白、边透明
- 输入聚焦/常态: 常态即有 2px 加粗下边线（Fluent 底线风格）
